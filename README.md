# 挖个僵尸 · Demo 0.9.1

基于 Cocos Creator 2.4.6 的竖屏网页试玩。

试玩：https://fuhao-dev.github.io/wage-zombie-demo/

触摸场地移动发光鞭圈，催促尸工开工；升级扩大范围，招募尸工与伙伴。
下方升级选项支持上下拖动、惯性滚动和鼠标滚轮。点击购买，长按查看详情。
满级选项灰显并显示“达到上线”。右上试剂瓶可进入章节及转场展示。

本次修正棺材作业盔的比例、位置与开盖层级，避免遮住眼睛和牙齿；
棺材停工保留摇柄角度，晕眩停止加工反馈；切割尸工停工保留锯片角度。
玩法、价格、成长数值、存档键和美术PNG保持。

GitHub Pages 使用 main 分支根目录；保留 .nojekyll 与相对资源路径。
本仓库仅包含网页运行文件，进度保存在浏览器本地。
