# 挖个僵尸 · Demo 0.9

基于 Cocos Creator 2.4.6 的竖屏网页试玩。

试玩地址：https://fuhao-dev.github.io/wage-zombie-demo/

触摸或按住鼠标移动发光鞭圈，催促尸工开工作业；升级扩大范围，招募尸工与伙伴。
右上角试剂瓶可进入章节展示，查看第二幕改造尸工、伙伴装备及“墓园入厂”转场。

本次版本包含：

- 第二幕四类改造尸工拆件动画。
- 幽灵监工、活体碎骨棺的基础、作业盔、载具状态。
- 墓园入厂转场、结算与章节存档恢复。
- 绿色体液与反馈效果。

本仓库包含网页运行文件；浏览器本地保存试玩进度。

## 发布更新

GitHub Pages 使用 `main` 分支的根目录。将新版网页运行文件更新到仓库并提交，Pages 会自动重新发布。
保留根目录的 `.nojekyll`，并保持所有资源路径相对于页面。
